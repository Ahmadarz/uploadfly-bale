# Fonts

All fonts here are self-hosted (Google Fonts is blocked in Iran) and licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling them in apps.

| File prefix | Font | Used for |
|---|---|---|
| vazirmatn-* | Vazirmatn (Saber Rastikerdar) | Persian |
| ibm-plex-sans-arabic-* | IBM Plex Sans Arabic (IBM) | Arabic |
| onest-* | Onest | English, Russian body, numbers |
| unbounded-* | Unbounded | English/Russian headings, wordmark |

Chinese uses the phone's system fonts (PingFang SC, Noto Sans SC, Microsoft YaHei).
Files come from the @fontsource npm packages (woff2 subsets).
